# Company logos

Drop logo files here, then point at them from the matching experience file:

1. Save the file, e.g. `behinbazar.svg` or `lancer.png`
2. Open `src/content/experience/behinbazar.md`
3. Change the frontmatter line `logo: TODO` to `logo: /src/content/experience/logos/behinbazar.svg`

SVG is best. If you only have PNG, use a transparent background and at least 200x200 px.
Until a real file is set, the site shows a clean monogram (the `monogram:` letters) instead.
