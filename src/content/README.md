# Content

Everything a visitor reads lives in this folder. Nothing here is code you need to understand.

- design-tokens.js  colours, fonts, radii, spacing, motion. The whole design system.
- site.config.js    name, roles, contact details, links, resume path, category order.
- sidebar.config.js the icon rail: which icons, in what order.
- about.md          the About page text.
- skills.json       skill groups.
- services.md       one service per ## heading.
- process.json      the three step How I Work map.
- experience/       one markdown file per job.
- projects/         one markdown file per project. Add a file, get a new case study.

Step by step instructions are in EDITING-GUIDE.md at the top of the project.
