# Images

Use a clean portrait for `profile.jpg`: square, 600x600 or larger, face and shoulders only.
Do not include a decorative ring, the letters AA, a frame, or text inside the image. The site
adds the circular blue/cyan glow ring and the AA fallback itself. A wide banner or an image
that already contains a ring will be cropped badly inside the circular avatar.

Project screenshots can live here too. Reference them from a project file as `/images/name.png`.
